# PJ-Racing

A 3D lego kart racer in the spirit of classic kart games: lego karts, street racers and
**monster trucks**, items, drifting with mini-turbos, ramps with tricks, a garage where you build
your own car from lego parts, and progression where winning races unlocks new parts, paints and
upgrades. 1 to 4 players on one machine (split-screen) with USB PS2 pads and/or the keyboard.

Everything (cars, tracks, scenery, textures, sound effects and music) is generated by code, so the
repo has no asset files.

## Quick start

```bash
./build.sh setup     # installs Godot 4.7.2 through mise and imports the project
./build.sh run       # play!
```

| Command | What it does |
|---|---|
| `./build.sh run` | Play the game |
| `./build.sh editor` | Open the project in the Godot editor |
| `./build.sh check` | Smoke test: every screen, CPU races on all 7 tracks, an arcade race and a full 2-player tournament |
| `./build.sh export` | Build a standalone Linux executable in `build/` (downloads export templates the first time) |
| `./build.sh install` | Export the game and install it for your user (`~/.local`): app-menu entry, icon and a `pj-racing` command. No sudo needed |
| `./build.sh uninstall` | Remove the user install (your save and garage are kept) |
| `./build.sh pads` | List the connected game controllers |
| `./build.sh reset-save` | Back up and reset your progress |
| `./build.sh clean` | Remove caches and build output |

`mise run run`, `mise run check`, etc. also work.

## Made for kids (around 10 years old)

The main menu has just three big buttons:

- **RACE!**: pick one of your 4 cars, pick a track, go.
- **BUILD YOUR CAR**: the garage, which is the heart of the game. Every car starts as a **base car**:
  a go-kart frame, classic wheels, a tiny motor and a driver. From there you add things: choose a
  tab (Car Type, Body, Engine, Wheels, Wing, Paint, Driver, Extras) and click part tiles to snap them
  on with a brick-burst. **Extras** stack (up to 8): big headlights, bull bar, side pipes, mud flaps,
  racing flag, bouncy antenna, siren, roof light bar, bull horns, shark fin, rocket boosters and a
  race number. Open cars automatically get a roll bar to hold roof extras. Stats are shown as lego
  studs and highlighting a part previews it, with green/red studs for what changes.
  **Surprise Me!** makes a random combo, **Start Over** goes back to the base car, and **New Name**
  gives the car a silly name ("Turbo Taco", "Pickle Rocket"…).
- **RACE WITH FRIENDS**: 2–4 players split-screen, cups of 3 or 6 races with points and a podium.

**Help tips while racing**: a coach box pops up at the right moment with the player's own buttons:
what an item does when you get it ("BRICK MISSILE! Press [E or L1] to fire it…"), a reminder if you
forget to use it, how to drift in a big turn and when to let go for the turbo, tricks on jumps, getting
back on the road, and more. Each tip shows only a few times. Turn them off in **Settings**.

**Easy Driving** is on by default: the gas is automatic, the kart gently steers back toward the
road, wall hits are softer, and a stuck kart is put back on the track after 2 seconds. Kids only
need to steer, drift and use items. Turn it off in **Settings** for a real challenge. Settings also
holds race length, number of computer racers and computer skill (Easy by default).

**Everything is open**: for now every part is available from the start, with no prices, locks or
studs shop (`FREE_MODE` in `src/autoload/parts.gd`). Setting it to `false` brings back the
progression that is already built: studs for every race, races unlocking new parts with NEW! stickers,
buying parts and Power-Up upgrades.

## Tracks

| Track | Theme | Notes |
|---|---|---|
| Brick Park | Meadow | Easy, gentle hill |
| Dusty Dunes | Desert | Hills, bumps, 3 ramps |
| Frosty Peaks | Snow | Big climb and hairpin descent |
| Neon Nights | City at night | Tight corners, lots of boost pads |
| Lava Foundry | Volcano | Raised roads over lava (falling in respawns you) |
| Monster Mud Pit | Mud | Wide, bumpy, 4 big ramps; monster trucks shine here |
| Starlight Skyway | Outer space | Glowing rainbow road floating among planets, rockets and UFOs, with an overpass and low gravity for floaty jumps |

Every track also has corner arrow signs, banner arches with balloons, flags on the walls and its own
scenery (houses and windmills, tents, igloos, billboards, barrels…). Cups: Stud Cup, Turbo Cup,
Star Cup (ends in space) and the 6-race Grand Brick Prix.

## Controls

| Action | Keyboard left (WASD) | Keyboard right (Arrows) | PS2 pad |
|---|---|---|---|
| Steer | A / D | ← / → | Left stick or D-pad |
| Accelerate (only with Easy Driving off) | W | ↑ | Cross ✕ (or R2) |
| Brake / reverse | S | ↓ | Square ▢ (or L2) |
| Drift / hop | Space | `.` | R1 or Circle ○ |
| Use item | E / F | Enter | L1 or Triangle △ |
| Look behind | Q | `,` | Select |
| Pause | Esc | Backspace | Start |

In Arcade (single player), both keyboard halves and every pad control player 1. In Versus, each pad
and each keyboard half is a separate player: press **Cross/Start** on a pad, **Space** or **Enter** on
the keyboard to join.

Generic PS2-to-USB adapters are usually recognized automatically. If the buttons come out wrong,
open **Controls** in the main menu: it has a live button tester and lets you remap the pad buttons
(the mapping applies to all pads).

**F11** toggles fullscreen, **F3** shows FPS.

### Driving tips
- **Drift**: hold drift while turning. Sparks go blue → orange → purple; release for a mini-turbo.
- **Rocket start**: hold accelerate during the countdown.
- **Ramp tricks**: press drift in the air after a ramp for a boost when you land.
- **Monster trucks** barely slow down off-road and *crush* karts they land on.
- **Items** (from the rainbow `?` bricks): Turbo, Triple Turbo, Brick Missile (homes onto the racer
  ahead of you), Oil Slick (drops behind you), Shield (blocks one hit). Racers further back get better items.

## Project layout

```
build.sh                 one entry point for setup/run/check/export
mise.toml                pins Godot 4.7.2
project.godot            GL Compatibility renderer (fast on integrated Intel GPUs), Jolt physics
src/
  main.gd                root node, screen host, CLI test flags
  autoload/
    parts.gd             lego parts catalog + stat math
    save.gd              profile: studs, unlocked parts, garage builds, upgrades, settings
    controls.gd          per-player input actions bound to a device (pad / keyboard half)
    sfx.gd               synthesized sound effects, engine loop and chiptune music
    game.gd              screen routing, race setup, tournaments, rewards
  data/tracks.gd         track layouts, cups and visual themes
  lego/
    lego_mesh.gd         brick/stud/cylinder geometry merged into few draw calls
    lego_car.gd          builds a car model from a part build
    tex.gd               procedural textures (baseplate, road, curbs…)
  race/
    race.gd              race controller: grid, split-screen, countdown, laps, positions, pause
    track.gd             spline road, walls, ramps, boost pads, item boxes, scenery
    kart.gd, kart_ai.gd  arcade physics + CPU drivers
    hud.gd, chase_cam.gd, projectiles.gd, item_box.gd, boost_pad.gd, fx.gd
  ui/                    title, arcade, versus lobby, track/cup select, garage, controls,
                         settings, results screens + shared widgets
```

### Extending
- **New track**: add an entry in `src/data/tracks.gd` (`points` is a closed loop of `Vector3(x, height, z)`;
  the first point is the start line). Ramps, boost pads and item boxes are auto-placed on straights.
- **New part**: add an `_add(...)` line in `src/autoload/parts.gd` and its geometry in `src/lego/lego_car.gd`.

### Developer flags
```bash
./build.sh run -- --race mud              # straight into a race
./build.sh run -- --race city --players 4 # 4-way split-screen
./build.sh run -- --demo lava             # all-CPU race
./build.sh run -- --screen garage         # open a screen directly
```
Add `--autoplay` to let the AI drive the player karts. Test runs (`--demo`, `--autoplay`, `--screen`)
use a separate throwaway save, so they never touch your progress.
